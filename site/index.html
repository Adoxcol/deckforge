Features

Everything a deck should do. Nothing it shouldn’t.

Build

Make every press count.

Tap, double-press, hold

Give one key three actions. A double-press waits a beat to tell itself apart from a tap; a hold fires once the key stays down.

Macro chains

Shortcuts, waits, “if running” checks, app launches, profile switches and HTTP webhooks, timed block by block.

Faces that move

Icons, titles, brand logos, and GIFs that animate on the hardware. Search Wikimedia Commons or start from CC0 animations.

Shortcuts catalog

Ready-made Windows, editing, game-recording and browser hotkeys, each still editable, or record your own keybind.

Control

Run your setup from the deck.

OBS Studio

Stream, record, pause, replay buffer, virtual camera, studio transitions, named scenes and source mutes over OBS WebSocket.

Per-app audio on knobs

Turn Spotify down without touching Discord. Knobs step one app’s volume by 2%, push to mute, and the key shows the level.

Game Mode

Close the apps and services you pick, switch power plan if you like, and put everything back when you’re done.

Plugins

Runs Stream Deck and Stream Dock .sdPlugin plugins. Each one stays off until you turn it on.

Stay out of the way

Reliable enough to forget about.

Lives in the tray

Close the editor and the deck keeps working. Unsaved edits are kept as a recovery draft in case of a crash.

Survives USB drops

A heartbeat keeps the firmware awake, the layout is re-sent after a reconnect, and unchanged key images are skipped.

Fair to the vendor app

If the AJAZZ app is running, DeckForge lets go of the deck and waits for you. It never closes the other app for you.

Bring your setup

Import Stream Dock .sdProfile files, and share profile packs with their macros, pictures and animations.

Hardware

What works today, stated plainly.

DeckForge talks to decks directly over USB HID. One model is tested on real hardware. Drivers for more are written, and each will be switched on once it has been checked on a real device.

Tested on hardware

Ajazz AKP05E Pro

USB 0300:3013 · CRT-V4 protocol

Keys
10 LCD keys, 112×112
Touch strip
800×100, 4 zones, swipe
Knobs
4, push to click, LED rings
Deck control
Brightness, heartbeat, auto-reconnect

Driver written, not yet enabled

  • Ajazz AKP05E, Ajazz N4 Pro CRT-V4 Same protocol as the Pro; not yet allowed on the live connection.
  • MiraBox N3 / Ajazz AKP03, MiraBox 293S CRT-V2 Protocol defined; never run against a real device.
  • Elgato Stream Deck MK.2, +, XL Elgato HID Protocol defined; never run against a real device.

Own one of these? Open an issue. A hardware report is how a driver gets verified.

Open source

Open source, and open about it.

DeckForge is GPL-3.0. Rust talks to the hardware and to Windows, React draws the editor, and Tauri holds the two together in a small, signed installer.

Every release says what was checked by automated tests and what was checked on a physical deck, and names device families that have protocol code but haven’t been verified.

  • Tauri 2
  • Rust
  • React 19
  • TypeScript
  • Tailwind CSS 4
  • HIDAPI
Build from source 
# Node.js 22 and Rust 1.90 (pinned in rust-toolchain.toml)
git clone https://github.com/Adoxcol/deckforge.git
cd deckforge
npm install
npm run tauri dev

No deck? npm run dev opens the editor in a browser with demo data.
